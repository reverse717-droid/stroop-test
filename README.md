# Stroop-тест

Веб-приложение для прохождения классического теста Струпа.

## Запуск

```bash
npm install
npm run dev
```

## Тесты

```bash
npm run test        # watch mode
npm run test:run    # один прогон
```

## Формулы

- **Среднее RT** = сумма времён реакции правильных ответов / количество правильных
- **Индекс интерференции** = среднее RT неконгруэнтных − среднее RT конгруэнтных
- **Точность** = (правильные / всего) × 100%
